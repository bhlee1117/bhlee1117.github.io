Vibe coding

Vibe coding projects

Tools I build with AI coding assistants to plan experiments, organize the literature, run the bench and show data. Each one started as a problem in my own research.

BrainCAD

3D stereotaxic planning for injections, implants and optical access

Puts the mouse brain atlas, stereotaxic targets, pipettes, cannulas, prisms, objectives and custom hardware into one 3D scene, to answer whether a target can be reached with a given object, at a given angle, without hitting anything.

  • Atlas viewer with region lookup and orthogonal slice views
  • Import STL/OBJ/GLB hardware; collision and clearance checks
  • Objective-view renders and axon-projection back-tracing
  • TypeScript
  • three.js
  • Vite
  • Allen CCFv3

PaperTree

A literature atlas built around claims, not papers

Turns a Zotero collection into a map of what the field claims, which papers support, qualify or contradict each claim, and where the evidence is thin. The live atlas covers dendritic computation.

  • Papers labelled by preparation and measurement; claims written by hand
  • Flags claims that rest on a single preparation
  • Incremental updates: only new papers are processed
  • Python
  • Claude API
  • OpenAlex
  • Zotero

Genesis

A shared cloning designer for the lab’s plasmid inventory

Indexes the plasmid files on the lab share, normalizes them into a searchable inventory of plasmids and reusable parts, validates a construct in silico, and generates ranked cloning routes with a primer table and a step-by-step protocol.

  • Reads GenBank, ApE, SnapGene and FASTA files
  • Collapses duplicate plasmids saved by different people
  • Runs on a stock Python install, no network needed
  • Python
  • SQLite
  • Vanilla JS

Prism voltage movie

A data-driven 3D movie of dendritic voltage in vivo

A Blender pipeline that places reconstructed CA1 neurons inside a 3D model of the prism implant and drives their color with recorded dendritic voltage, alongside kymographs, the optogenetic stimulation pattern and MouseLight axon reconstructions.

  • Recorded voltage mapped onto traced dendrites
  • Unmeasured branches filled in with a passive cable model
  • 1 ms of data per frame, rendered at 1080p
  • Blender
  • Python
  • Geometry Nodes
  • MATLAB
